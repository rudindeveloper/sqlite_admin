# SQLite Web Admin

Легковесная веб-админка для просмотра и управления файлами баз данных SQLite, написанная на чистом Python без каких-либо внешних библиотек и зависимостей.

Работает из коробки на любой машине, где установлен **Python 3.8+** (`http.server`, `sqlite3`, `json`, `urllib`).

---

## Возможности

- **0 внешних зависимостей**: не требует `pip install`, `virtualenv` или компиляции.
- **Защита паролем**:
  - Опциональная авторизация через флаг `--password` (или `-P`) либо переменную окружения `SQLITE_ADMIN_PASSWORD`.
  - Модальное окно входа при открытии в браузере, безопасные сессии через cookie (`HttpOnly; SameSite=Lax`), защита от тайминг-атак (`hmac.compare_digest`).
  - Кнопка «Выйти» в шапке панели.
- **Светлая тема по умолчанию**: современный интерфейс с высокой контрастностью и переключателем на тёмную тему.
- **Типографика из Google Fonts**:
  - Выбор шрифта прямо из интерфейса: *Geologica, Inter, Roboto, Open Sans, Outfit, Montserrat, JetBrains Mono, Fira Code, Source Code Pro* или системный шрифт.
  - Настройка размера текста (12px — 18px).
  - Настройка толщины шрифта / веса (300 Light — 700 Bold).
  - Выбранные настройки шрифта и темы автоматически сохраняются в `localStorage` браузера.
- **Навигация по структуре БД**:
  - Список таблиц и представлений (*views*) в боковой панели.
  - Количество строк для каждой таблицы.
  - Живой поиск/фильтрация по названию таблиц.
- **Просмотр данных**:
  - Быстрая таблица с фиксированным заголовком.
  - Пагинация с выбором размера страницы (25, 50, 100, 500 записей).
  - Сортировка данных по клику на заголовок колонки (ASC / DESC).
  - Подсветка значений `NULL` и безопасное представление бинарных данных (`BLOB`).
- **Схема и DDL**:
  - Исходный SQL `CREATE TABLE / VIEW`.
  - Таблица колонок: имя, тип, флаг `NOT NULL`, значение по умолчанию, бейдж `PRIMARY KEY`.
  - Список внешних ключей (*Foreign Keys*) и индексов.
- **SQL-консоль**:
  - Выполнение произвольных SQL-запросов (`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `ALTER` и скриптов).
  - Горячая клавиша **`Ctrl + Enter`** (или `Cmd + Enter`) для быстрого выполнения.
  - Замер времени выполнения в миллисекундах и количество затронутых строк.

## Быстрый старт

### 1. Запуск с указанием файла базы данных

```bash
# Базовый запуск (откроется на http://127.0.0.1:8080)
python app.py путь/к/вашей_базе.db

# Запуск с защитой паролем
python app.py путь/к/вашей_базе.db --password "мой_пароль"

# Или через переменную окружения
# Windows PowerShell:
$env:SQLITE_ADMIN_PASSWORD="мой_пароль"; python app.py путь/к/вашей_базе.db
# Linux / macOS:
SQLITE_ADMIN_PASSWORD="мой_пароль" python app.py путь/к/вашей_базе.db

# Запуск с указанием пользовательского порта и хоста
python app.py путь/к/вашей_базе.db --port 9000 --host 0.0.0.0
```

### 2. Автоматический поиск базы данных

Если запустить скрипт без аргументов:
```bash
python app.py
```
Админка автоматически найдёт первый попавшийся файл с расширением `.sqlite`, `.sqlite3` или `.db` в текущей папке. Если файлов нет — будет создана чистая база `database.sqlite`.

## Демонстрационная база данных

В репозиторий включён скрипт генерации тестовой базы данных `demo.db` с пользователями, товарами, заказами и представлениями:

```bash
# Создать или пересоздать demo.db
python seed_demo.py

# Запустить админку для demo.db
python app.py demo.db
```

После запуска откройте в браузере: [http://127.0.0.1:8080](http://127.0.0.1:8080).

## Тестирование

Для запуска набора модульных тестов выполните:

```bash
python test_app.py
```

Тесты проверяют:
- Получение списка таблиц и подсчёт строк;
- Извлечение DDL, колонок, индексов и связей;
- Пагинацию, сортировку и форматирование данных (включая BLOB);
- Выполнение запросов на чтение и запись, обработку ошибок;
- Работу всех эндпоинтов HTTP API (`/api/info`, `/api/tables`, `/api/table/<name>/data`, `/api/table/<name>/schema`, `/api/query`).
